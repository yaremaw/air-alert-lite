# Strike Alert

A real-time air war on a live air-alert map, made in Godot.

## Opening the game

1. Install **Godot 4.7.2** (the standard build, not .NET): https://godotengine.org/download/archive/4.7.2-stable/
2. Download this branch: on GitHub press **Code → Download ZIP** and unzip it, or clone it:
   `git clone -b feature/modern-military-command-map https://github.com/yaremaw/air-alert-lite.git`
3. Start Godot, press **Import**, and pick the `project.godot` file in the downloaded folder.
4. The first time, Godot imports all the pictures and sounds; that takes a minute.
5. Press **F5** (or the ▶ button in the top right) to play.

## Controls, briefly

- 1–5: build (factory, refinery, AA gun, SAM, radar); Q / W / E: strike with drones, cruise or ballistic missiles
- Click enemy land to strike; hold and drag to draw the route
- Double-click one of your AA guns to take it yourself (mouse aims, hold left button to fire, WASD drives)
- Space: pause · 1×/2×/3×: speed · T: statistics · Esc: menu · F11: fullscreen

The game's own tips explain the rest the first time you play.
